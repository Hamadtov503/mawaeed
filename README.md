# مواعيدي 📅

تطبيق آيفون (SwiftUI) بسيط ومركّز على **المواعيد** — نبنيه حبة حبة.

## التثبيت (TrollStore)

كل `push` على `main` يبني التطبيق في GitHub Actions وينشره في Release اسمه **`latest`** باسم فيه رقم البناء (مثلاً `Mawaeed-12.ipa`).
افتح صفحة الـ Releases من الجوال ← اضغط ملف الـ ipa ← **Open in TrollStore**.
رقم البناء يطلع تحت في الإعدادات: «الإصدار 1.0 (12)».

## اللي فيه الحين

- **الرئيسية:** ترحيب وأزرار، بطاقة التاريخ (هجري أم القرى + ميلادي)، بطاقة مواعيد اليوم والأسبوع، **عدّاد تنازلي حي بالثانية** لموعدك الجاي مع شريط تقدّم، وبطاقة تذكير لو موعدك اليوم (تفتح الموقع في الخرائط).
- **مواعيدي:** القادمة مجمّعة باليوم، السابقة، وتقويم تختار منه يوم. مع بحث.
- **إضافة / تعديل:** عنوان مع اقتراحات سريعة، تاريخ بالميلادي أو الهجري، وقت محدد أو طوال اليوم، المكان، ملاحظات، وتنبيهات (من وقت الموعد إلى قبل أسبوع).
- **التنبيهات:** قبل الموعد بالأوقات اللي تختارها + **ملخص الصباح** للأيام اللي فيها مواعيد. الضغط على التنبيه يفتح الموعد.
- **المزامنة بين الأجهزة (iCloud Drive):** اختر نفس المجلد في كل جوال، وتنتقل الإضافات والتعديلات والحذف بينها.
- **تقويم iCloud:** المواعيد تنضاف لتقويم «مواعيدي» وتطلع في الجوال والماك والساعة.
- **نسخة احتياطية يدوية:** تصدير واسترجاع ملف.

> الصفحات ما تنفتح بأسلوب "الدفع" (push)؛ تفاصيل الموعد والنموذج تطلع كـ sheet من تحت — لأن صفحات الدفع كانت تنرسم معكوسة أثناء الحركة في الاتجاه من اليمين لليسار.

## البنية

```
Sources/
├─ App/MawaeedApp.swift
├─ Model/       Appointment, Formatters (هجري/ميلادي، العد بالعربي)
├─ Services/    Store, NotificationManager, CalendarSync, SyncManager, AppSettings
└─ Views/       Home, Appointments, AppointmentDetail, AppointmentEditor, Settings, Theme
```

البيانات في `Application Support/appointments.json`. عند أول تشغيل بعد التحديث تنتقل المواعيد فقط من الإصدار القديم (`items.json`).
