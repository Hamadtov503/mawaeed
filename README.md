# مواعيدي 📅

تطبيق آيفون (SwiftUI) تسجّل فيه كل شي له تاريخ، ويذكّرك قبله:
مواعيد، انتهاء استمارة السيارة، الرخصة، الهوية، الجواز، التأمين، الفحص الدوري، باقات النت والجوال، الاشتراكات، الفواتير والأقساط، ضمان الأجهزة، الصيانة الدورية، والمهام.

## التثبيت (TrollStore — مثل تطبيق الديوانية)

كل `push` على `main` يبني التطبيق تلقائياً في GitHub Actions وينشره في Release اسمه **`latest`**.
افتح صفحة الـ Releases من الجوال ← اضغط `Mawaeed.ipa` ← **Open in TrollStore**.

> تقدر بعد تفتح المشروع في Xcode على الماك: `xcodegen generate && open Mawaeed.xcodeproj`، واختر حسابك في Signing وشغّله على جوالك.

| **هجري وميلادي** | كل تاريخ ينعرض بالتقويمين، وتقدر تدخل التاريخ بالهجري (أم القرى) — مفيد للوثائق القديمة. |

| **صور ومرفقات** | صوّر الاستمارة أو الفاتورة أو كرت الضمان وأرفقها مع العنصر. |
| **كم تصرف شهرياً** | لو حطيت مبلغ للاشتراكات والفواتير، الرئيسية تعرض مجموعها الشهري التقريبي. |
| **عدّاد على الأيقونة** | رقم على أيقونة التطبيق = المتأخر + المستحق اليوم. |
| **بحث وفلترة** | حسب النوع، وتجميع حسب الشهر، وقائمة للمنجزة. |
| **مشاركة ونسخ** | شارك العنصر (نص + صور) بالواتساب، أو سوّ منه نسخة مكررة. |
| **قفل Face ID** | اختياري من الإعدادات. |

## الربط مع iCloud ☁️

خدمة CloudKit (المزامنة المباشرة) تحتاج حساب Apple Developer مدفوع وتوقيع رسمي، وما تشتغل مع TrollStore. عشان كذا الربط مسوّى بثلاث طرق تشتغل بدون أي اشتراك:

1. **تقويم iCloud** — يسوّي تقويم اسمه «مواعيدي» داخل حسابك في iCloud ويحط فيه كل العناصر، فتشوفها في الماك والآيباد والساعة وأي تقويم مربوط.
2. **تطبيق التذكيرات** — المهام تنرسل لقائمة «مواعيدي» في Reminders، ولو علّمتها منجزة هناك (من أي جهاز) تنعلّم منجزة في التطبيق بعد.
3. **نسخ احتياطي تلقائي على iCloud Drive** — تختار مجلد مرة وحدة، وكل تعديل ينحفظ هناك كملف JSON (مع الصور). لو غيّرت جوالك: ثبّت التطبيق ← الإعدادات ← «استرجع من نسخة».

## البنية

```
.
├─ project.yml               ← XcodeGen
├─ Sources/
│  ├─ App/MawaeedApp.swift
│  ├─ Model/                 ← Item, Templates, Formatters (هجري/ميلادي، العدّ بالعربي)
│  ├─ Services/              ← Store, NotificationManager, CalendarSync, BackupManager, PhotoStore/AppLock, AppSettings
│  └─ Views/                 ← Home, All, Detail, Editor, AddFlow, Settings
└─ Resources/                ← الأيقونة والألوان
```

البيانات تنحفظ في `Application Support/items.json` على الجوال، والصور في `Documents/photos`.
الحد الأدنى iOS 15.
